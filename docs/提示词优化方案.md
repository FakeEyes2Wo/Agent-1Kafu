# 提示词优化方案

## 目标

本轮优化聚焦回答质量与幻觉抑制，不改变检索、索引、图片后处理和模型后端。目标是让模型更稳定地做到：

- 只基于用户问题、图片摘要、RAG 证据和通用政策回答。
- 避免把检索噪声、手册标题、目录、页码、相邻无关段落写进答案。
- 减少无证据的时效、金额、责任、免费承诺、兼容性和保修期限。
- 降低客服套话和泛化补充材料清单对有效答案的稀释。
- 保持 `<PIC>` 输出只作为裸占位符，图片 ID 继续由后处理追加。

## 观察到的风险

1. **检索上下文含噪**
   手册 chunk 可能包含标题、目录、安全警告、多个型号分支或相邻段落。强模型和 thinking 模式容易把这些内容完整复述，导致答案冗长或偏题。

2. **通用政策与商品手册混用**
   退换货、发票、物流、投诉等通用客服题如果引入商品手册，会产生无关型号、保修期或授权经销商信息。

3. **无证据承诺**
   客服模型容易补充“免费处理”“马上到账”“一定可以更换”等承诺。赛题强调幻觉抑制，这类内容应在证据不足时删除或改成需核实。

4. **步骤题过长**
   手册型问题需要可执行步骤，不需要完整背景、警告、目录或多型号无关分支。过长答案也会增加图片漂移风险。

5. **图片格式风险**
   模型不能直接输出图片 ID。最终答案只允许正文裸 `<PIC>`，由系统根据检索上下文追加末尾图片列表。

## 已落地的提示词策略

### 生成初稿

`ANSWER_PROMPT` 增强了 RAG 证据纪律：

- 明确“检索证据可能含有噪声、目录、标题或相邻无关段落”。
- 要求只采用与问题中的商品、部件、状态、动作或政策关键词直接匹配的句子。
- 禁止复制来源标签、手册标题、目录、页码、章节标题、Markdown 标题符号和无关安全警告。
- 将幻觉禁止项扩展到参数、时效、费用、责任、免费承诺、兼容性、保修期限和绝对结论。
- 步骤题通常压缩为 3-5 个关键步骤，避免整段复述手册。
- 英文问题也使用同一套 evidence discipline。

### 质检改写

`CHECK_AND_REWRITE_PROMPT` 增强了二次过滤：

- 把“检索噪声、目录、标题和相邻无关段落不能当作回答事实”列为 RAG 一致性检查。
- 在幻觉检查中增加兼容性和保修期限。
- 在简洁性检查中删除来源标签、手册标题、目录、页码、Markdown 标题符号。
- 要求步骤题压缩为 3-5 个关键步骤，删除多型号无关分支和背景说明。

## 消融建议

建议在服务器上比较以下版本：

1. `CHAT_ENABLE_THINKING=false`，无 rerank，当前 prompt。
2. `CHAT_ENABLE_THINKING=false`，开启 Bailian rerank，当前 prompt。
3. `CHAT_API_BACKEND=openai_responses`，`OPENAI_RESPONSES_REASONING_EFFORT=none`，当前 prompt。

每次生成后先做格式与内容体检：

- 400 行是否完整。
- 是否存在空答案、重复 id、Traceback/API error 泄露。
- 是否存在 `根据说明，` 或 `According to the available manual information` 大量兜底。
- `<PIC>` 是否都有末尾图片列表。
- 是否仍有 `#` 标题、手册目录、来源标签或图片 ID 残留。

## 注意事项

这次优化只提高 prompt 约束，不保证解决检索错召回。如果错误证据排在前列，模型仍可能基于错误证据作答。后续更高优先级的改进应结合 rerank、子问题拆分和 evidence verifier。
